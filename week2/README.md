# Week 2 – Data Visualization and Insight Generation

## Overview

This Week 2 project focuses on transforming cleaned agribusiness data into meaningful visual insights using data visualization techniques. The analysis was performed using the `crops.csv` dataset, which contains information on crop production, cultivated area, seasons, and crop years across different regions. The objective was to identify production patterns, relationships between variables, and trends that can support better decision-making in the agribusiness sector.

The project was completed using **RStudio (Posit Cloud)**, where exploratory data analysis was performed before creating visualizations. Four different charts were developed to represent the dataset from multiple perspectives: a crop-wise distribution bar chart, a production distribution histogram, an area versus production scatter plot, and a yearly production trend line graph. These visualizations helped simplify complex agricultural data and made it easier to understand production behavior across different conditions.

The analysis revealed that production values are highly unevenly distributed, with most observations concentrated at lower production levels and a few records showing exceptionally high values. The scatter plot indicated a generally positive relationship between cultivated area and production, while the yearly trend graph highlighted fluctuations in agricultural output over time.
