# Week 1 – Data Collection, Cleaning, and Initial Analysis of Agribusiness Data

## Overview

This Week 1 project focuses on the initial stages of the data analysis workflow using an agribusiness dataset. The objective was to collect publicly available agricultural data, clean the dataset to improve its quality, and perform exploratory data analysis (EDA) to understand its characteristics. The selected dataset (`crop.csv`) contains agricultural production information with attributes such as FAO indicator codes, source codes, element codes, values, and supporting fields.

The project began by identifying reliable public data sources, including **FAOSTAT**, **Data.gov.in**, and **Kaggle Agricultural Datasets**. After collecting the dataset, several preprocessing steps were performed using **Python 3.13** and the **Pandas** library. These included checking the dataset structure, verifying data types, identifying missing values, removing duplicate records, filling missing numerical values where necessary, generating descriptive statistics, and examining possible outliers using box plots.

Exploratory Data Analysis provided valuable insights into the distribution and variation of agricultural indicators. Histograms and box plots helped visualize the spread of numerical variables, while statistical summaries offered an overview of the dataset's characteristics. The cleaning process improved data reliability and prepared the dataset for more advanced analytical tasks.
