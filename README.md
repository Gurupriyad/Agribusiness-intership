# Week 3 – Statistical Analysis and Agribusiness Forecasting

This repository contains the **Week 3 video recording** for my Agribusiness Internship assignment on **Statistical Analysis and Agribusiness Forecasting**.

## Assignment Overview

The objective of this task was to analyze historical crop production data using statistical techniques and develop a simple forecasting model.

The analysis was performed in **R (Posit Cloud)** using a dataset containing crop production records from multiple Indian states and districts (1997–2015).

## Work Completed

* Data cleaning and preprocessing
* Descriptive statistical analysis
* Pearson correlation analysis
* Linear regression analysis
* Forecast model using yearly average production
* Data visualization with three graphs
