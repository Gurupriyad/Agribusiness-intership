# Agribusiness-Week3
Agribusiness-Week3
Week 3 – Statistical Analysis and Agribusiness Forecasting

This repository contains the Week 3 submission for my Agribusiness Internship assignment on Statistical Analysis and Agribusiness Forecasting.

Objective

The objective of this task was to analyze historical crop production data using statistical techniques and develop a simple forecasting model using R (Posit Cloud).

Work Completed

Data cleaning and preprocessing

Descriptive statistical analysis

Pearson correlation analysis

Simple linear regression analysis

Forecast model using yearly average production

Data visualization with three graphs
